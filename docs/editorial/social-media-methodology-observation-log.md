## 1. 升级门槛

候选方法论必须满足：

1. 至少经过 3 个独立的正式周报或月报周期观察；
2. 每次报告都记录支持证据、反例或适用边界；
3. 达到 3 次后，统一输出一份“方法论核对稿”；
4. 只有作者确认后，才能写入正式通用规范或栏目 Playbook；
5. 未获确认的候选继续观察，不自动升级。

## 3. 每次报告的更新格式

每次周报或月报只追加新的证据，不重写历史记录。每个候选项记录：

```text
报告编号：
观察周期：
候选编号：
新增支持证据：
新增反例：
适用边界变化：
当前累计：x / 3
建议状态：继续观察 / 准备核对 / 暂停 / 否定
```

## 4. 达到三次后的统一输出

当独立观察周期达到 3 次时，输出一份方法论核对稿，至少包括：

- 建议升级为正式规范的结论；
- 仍需限制适用范围的结论；
- 被反例推翻或需要删除的结论；
- 每条方法的证据、反例和使用条件；
- 对现有通用规范、栏目 Playbook 和生产流程的具体修改建议。

在作者完成核对前，本文件中的内容只能作为写作假设和复盘框架使用。
