# 内容增长优化通用规范

状态：生效中的通用规范

适用范围：所有引用本仓库规范撰写、修改或复盘的微信公众号内容

本规范负责把内容研究中的增长结论转化为生产动作。它不要求每篇文章都追求最大流量，但要求每篇文章明确自己承担的任务，并完成适用的优化检查。

## 1. 强制使用规则

当任务中出现“遵循 `content-production-sop` 仓库规范”“按照仓库 SOP 撰写”或同等含义时，执行者必须：

1. 读取本规范、公众号通用写作规范和对应栏目 Playbook；
2. 在写作前确定本篇的内容模型、目标读者和主要优化目标；
3. 执行下方所有适用的 P0、P1、P2 项；
4. 对未执行的项目，明确标记“未采用、原因、是否需要作者确认”；
5. 在定稿前至少提醒作者核对一次未采用的优化项。

不得在没有说明的情况下跳过适用项目。

## 2. 通用优化任务

| 优先级 | 优化任务 | 必须执行的动作 | 主要观察指标 |
| --- | --- | --- | --- |
| P0 | 提高流量沉淀效率 | 首屏尽快兑现标题承诺；文末说明关注后能持续获得什么；避免只有泛化的“欢迎关注” | 每千次阅读新增关注 |
| P0 | 稳定内容生产流程 | 写作前载入结构、事实、格式和图片规范；保留事实依据；定稿前检查幻觉、格式与图片质量 | 人工重复提醒次数、返工原因 |
| P1 | 复用高质量产品内容结构 | 对产品、众筹和创业团队文章，检查是否具备“可信团队＋反常产品或需求＋异常结果＋商业解释” | 停留、分享、收藏、关注 |
| P1 | 改造深度文章标题 | 每篇使用可以独立成立的核心判断；系列编号退居次要位置；标题体现具体冲突、对象或结论 | 公众号消息打开率 |
| P1 | 提高普通文章基础盘 | 使用滚动中位数评价非爆款内容，不以单篇爆款替代基础盘改善 | 最近四篇成熟文章阅读中位数 |
| P2 | 建立用户反馈池 | 每周保留 3—5 条有代表性的评论、私信或聊天反馈；记录认可、疑问、误解和关注原因 | 有效反馈数量与重复主题 |

## 3. 写作前优化门

开始正文前，先回答：

- 本篇属于点击放大型、综合转化型、品牌深度型，还是尚未验证的新类型？
- 本篇首要任务是曝光、阅读深度、互动、关注转化，还是品牌表达？
- 标题吸引来的读者，能否在首屏立即看到与标题一致的内容？
- 本篇最希望读者记住的一个判断是什么？
- 文末是否能给出与账号长期定位一致的关注理由？

无法回答时，不应直接进入完整成稿。

## 4. 定稿前优化门

### 4.1 首屏承接

- 开头尽快说明文章对象、异常之处和阅读价值；
- 不用大段背景铺垫延迟兑现标题；
- 标题使用强冲突时，正文必须提供相应证据和解释；
- 不为点击制造正文无法回答的承诺。

### 4.2 内容与事实

- 关键数字、人物经历、产品参数和因果判断均可追溯；
- 明确区分事实、推测和作者判断；
- 不允许用更顺滑的表述掩盖证据不足；
- 发现无法验证的事实时，删除、降级表述或提醒作者确认。

### 4.3 标题

- 深度文章优先使用能够独立成立的核心判断；
- `（一）`、`（二）`等系列编号不能成为主要点击理由；
- 产品文章可以使用异常结果，但必须与正文分析能力匹配；
- 标题评审至少同时检查目标读者、点击承诺和正文兑现。

### 4.4 关注转化

- 文末说明账号长期更新什么，而不是只写“欢迎关注”；
- 关注理由应与本篇内容自然连接；
- 不以夸张福利或与账号定位无关的承诺换取关注。

### 4.5 图片与格式

- 图片必须与正文论点、产品机制或人物证据相关；
- AI 生成图不得伪装成真实人物、团队、产品或数据证据；
- 发布前核对图片清晰度、裁切、文字正确性和来源；
- 输出必须符合仓库现有排版、富文本和平台规范。

## 5. 复盘指标

达到 D+7 的文章，按以下四层评估：

| 层级 | 指标 |
| --- | --- |
| 分发 | 推荐流量占比、公众号消息打开率、D+1 至 D+7 流量曲线 |
| 消费 | 平均阅读时长、完读率 |
| 行动 | 分享率、收藏率、点赞、在看、评论 |
| 沉淀 | 新增关注、每千次阅读新增关注 |

尚未达到 D+7 的文章只记录生产状态和早期信号，不做最终成败判断。

## 6. 适用例外

- 品牌深度型文章可以优先追求观点质量和目标受众匹配，不强求与点击放大型文章相同的阅读规模；
- 非产品文章不强行套用“团队＋产品＋众筹结果”结构；
- 没有完整后台数据时，可以完成内容复盘，但必须标注数据缺口；
- 任何例外都需要显式说明，不得把“未检查”写成“无须优化”。
