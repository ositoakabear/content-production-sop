# Xiaohongshu Adaptation Rules

Use this guide when turning long-form article material into a Xiaohongshu post.

## Positioning

The Xiaohongshu version should not be a compressed WeChat article. It should feel like a mobile-native note: shorter, more direct, more visual, and easier to skim.

## Style

- Use first-person or close observer voice when natural.
- Keep paragraphs short.
- Use light emoji to mark sections, but do not over-decorate.
- Use factual claims consistently with the WeChat article.
- If the WeChat article changes a key fact, update the Xiaohongshu version too.

## Image Placeholders

Use explicit placeholders so images can be assembled later:

```markdown
(配图 1: 产品实物主图)
(配图 2: 使用场景图)
(配图 3: 功能细节或动图)
```

For paired states such as before/after, standing/fallen, on/off, or old/new, write the order clearly.

## Common Structure

```markdown
# <hook title>

<one short opening sentence>

(配图 1: <main visual>)

✨ **<highlight title>**
<2-4 short lines>

(配图 2: <scenario or detail>)

📊 **简单对比**
- **<product>**: ...
- **<alternative>**: ...

⚠️ **提醒**
<crowdfunding or purchase caveat>

#标签1 #标签2 #标签3
```

## Tags

Use three to nine tags:

- Product category
- Use scenario
- Target user
- Topic or series label
- Platform-specific discovery tags
