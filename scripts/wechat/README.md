# WeChat Scripts

Reusable scripts for WeChat article packaging and draft publishing.

## Files

- `publish_wechat.py`
  Uploads local/remote body images to WeChat CDN, uploads the cover image, and creates or updates a WeChat draft.

- `requirements.txt`
  Runtime dependency list for the script.

## Origin

The first version of this script was imported from `kickstarter-wechat-post-skill` so it can be reused by other content types.
